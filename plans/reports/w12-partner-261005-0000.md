## Design thesis (scaled, per uui skill)

- **Subject/job:** the partner portal is a scoped operations workspace — people, projects, work entries, money. The rebuild quiets the pre-UU ornament so the data carries the page.
- **Focal device:** the partner pages' decorative banner (radial hex glow + giant ring ornament + layered rgba shadows) is replaced by the UU surface idiom — `rounded-xl border border-input bg-card shadow-xs`, UU `font-display text-display-*` semibold headings, `outline-brand` focus rings. Quieter, consistent with the W10 auth treatment; all content and actions unchanged.
- **Palette:** role tokens stay authoritative under `data-partner-ui` (`--partner-*` block untouched): `bg-card`/`border-input`/`bg-muted` surfaces, partner `success/warning/info/destructive/primary` for status chips (WCAG-tuned per role; avoids a two-green drift against the fixed UU utility ladders). Zero new hex in partner files; raw-palette classes replaced with tokens (`text-teal-700`/`text-emerald-700`/`text-amber-800` → `text-info`/`text-success`/`text-warning`; `border-emerald-200 bg-emerald-50 text-emerald-800`, `border-red-200 bg-red-50 text-red-800` → success/destructive token tints; `border-slate-300 bg-white` → `border-input bg-card`; `bg-white/70` → `bg-card`).
- **Type:** `font-display text-display-sm/md/lg font-semibold` for page/banner headings (was bold/extrabold arbitrary sizes); card section headings → `font-semibold`. Eyebrows de-CAPS-ified to the UU idiom (`text-sm font-semibold text-brand-secondary`, no tracked-out caps) per the W10 eyebrow ruling.
- **Motion budget:** page-load stagger only; every `animate-fade-in-up` now `motion-safe:` (reduced-motion gets none). Two dead classes removed (below).
- **Counterfactual:** a generic migration would be "white cards + green buttons"; the anchors that make this TingTing's partner portal survive untouched — partner green identity, month-period selector, watermark stat tiles, rank leaderboard, global-pool claim flow, BCC/stmt export wiring.

## Icon policy (the seam rule)

Every icon rendered by owned JSX is now a verified `@untitledui/icons` export (each name verified via the Untitled UI MCP `search_icons` before import). Lucide remains **only** where an icon is passed as a component reference into shared components outside this wave's file ownership that type the prop as `LucideIcon`: `KpiHeroCard`, `PageHeader`, `EmptyState`, `MobilePageHeader`, `MobileOperationsPanel`/`MobileTaskRow`/`MobileOperationAction`, `GroupedStatCard`. Those seams retire when the owning components migrate (W-final); it is a type constraint, not an oversight. `MobileBottomNav`'s `icon` is loose (`ComponentType<{className?}>`), so the partner bottom-nav icons are fully UU.
