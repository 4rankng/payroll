## Icons — the load-bearing finding

`@untitledui/icons` components are plain `FunctionComponent`; lucide's `LucideIcon` is a `ForwardRefExoticComponent` (requires `$$typeof`). **tsc rejects UU icons in every shared slot typed `icon?: LucideIcon`** — verified empirically across `PageHeader`, `MobilePageHeader`, `MobileSectionHeader`, `GroupedStatCard`, `MobileOperationsPanel`, `DashboardSectionHeader`, `DashboardOverview`, `EmptyState`. Slots typed `React.ComponentType<{className?}>` (AdminSidebar MenuItem, MobileBottomNav nav types) accept UU icons cleanly.

Consequence (respecting "touch nothing outside my files"):
- **Full UU icon swap:** AdminSidebar (20 glyphs), AdminLayout (13), month bar + disclosure chips (mobile dashboard), ActivityUsersPage back arrow, settings error icons.
- **Contract-locked lucide stays:** desktop dashboard (all 8 icons feed DashboardSectionHeader/DashboardPriorityItem), settings PageHeader/MobilePageHeader icons, ActivityUsersPage header/empty icons, and mobile dashboard's SectionHeader/GroupedStatCard/MobileOperationsPanel icons. Each file carries a comment naming the exact blocker. The durable fix — widening shared icon props to `ComponentType<SVGProps<SVGSVGElement>>` (backward compatible) — is a shared-contract change outside this sub-wave's ownership; recommend scheduling it before W-final's lucide retirement.

All UU icon names verified via `search_icons` before import. Gap notes: UU has no `calendar-01`, `trending-up`, `landmark`, `history` — used `CalendarCheck01`/`CalendarDate`, `ArrowUpRight`, `Bank`, `ClockRewind` (glyph choices freely per plan ruling).
