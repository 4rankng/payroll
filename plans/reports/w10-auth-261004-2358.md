# W10 — Auth surfaces → Untitled UI PRO (report)

Wave: W10 of `plans/261004-1812-uu-full-migration/plan.md`. Executed by teammate `w10-auth`, 2026-10-04.
Scope: the five auth screens rebuilt as the first **native-UU surface wave** — UU primitives + FeaturedIcon + bridge tokens, not just restyled shadcn internals.

## Design thesis (scaled, per uui skill)

- **Subject/job:** TingTing auth = sign in or recover credentials with nothing competing. The wallet-hero panel stays the emotional center of `/login`.
- **Focal device:** the existing split hero (illustration + display headline, copy byte-identical); on the four card screens, UU `FeaturedIcon` brand/status moments — `ShieldTick` (OTP security), `MessageChatCircle` (Zalo channel), `CheckCircle` (success), `AlertCircle` (invalid link).
- **Palette:** bridge tokens only, zero hex — `bg-muted` canvas, `bg-card` + `border-input` + `shadow-xs` + `rounded-xl` surfaces, `brand-solid`/`text-brand-secondary` brand moments, `utility-error-*`/`utility-success-*` ladders for status (copy `fg-error-primary`/`fg-success-primary`, WCAG-checked on the tints), `outline-brand` focus throughout, `outline-error` semantics carried by the Input contract.
- **Type:** `font-display` + UU `text-display-sm/md/lg` semibold for card headings; hero headline keeps its existing display treatment.
- **Motion budget:** existing `animate-fade-in-up` (now `motion-safe:` so reduced-motion users get none) + pending spinners. Nothing else animates.
- **Counterfactual check:** a generic migration would be "white card + green button" for any product; the anchors that make this TingTing's are untouched — the wallet hero, the CCCD/phone identity input, the Zalo OTP channel, the CAPTCHA-on-failure flow.
